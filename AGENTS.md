# Base44 notes
- jOCD is a Java library (Gradle) for flashing ARM Cortex-M over CMSIS-DAP USB; it has no web UI or server.
- The Base44 preview serves the committed Javadoc (`docs/javadoc`) via nginx on port 3000. Edits to those HTML files show on refresh.
- Real usage needs physical USB hardware, which the sandbox lacks.
